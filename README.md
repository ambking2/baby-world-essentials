# سیسمونی جهان کودک — فروشگاه اینترنتی

فروشگاه اینترنتی کامل سیسمونی و پوشاک نوزاد با پنل مدیریت اختصاصی، راست‌به‌چپ و کاملاً فارسی.

## تکنولوژی

- **فرانت‌اند:** React 19 + TanStack Router/Start + TanStack Query + Tailwind CSS v4 + shadcn/Radix + lucide-react
- **بک‌اند:** Server Functions روی TanStack Start + دیتابیس SQLite با `node:sqlite` (بدون وابستگی اضافی)
- **انیمیشن:** CSS keyframes + `tw-animate-css` + اسکرول‌ریویل با IntersectionObserver
- **نمودارها:** recharts · **اعلان‌ها:** sonner · **اسلایدر:** embla

## پیش‌نیاز

- Node.js نسخهٔ **24 یا بالاتر** (برای `node:sqlite`)

## اجرا

```bash
npm install
npm run seed   # ساخت دیتابیس و دادهٔ اولیه
npm run dev    # اجرای محلی
```

برای خروجی نهایی:

```bash
npm run build
npm run preview
```

## متغیرهای محیطی

| متغیر | توضیح |
| --- | --- |
| `DATABASE_PATH` | مسیر فایل دیتابیس؛ پیش‌فرض `data/store.db` |
| `ADMIN_EMAIL` | ایمیل مدیر هنگام seed |
| `ADMIN_PASSWORD` | رمز مدیر هنگام seed |
| `MAIL_PROVIDER` | `resend` یا `brevo`؛ در نبود این متغیر ایمیل‌ها فقط در کنسول لاگ می‌شوند |
| `MAIL_API_KEY` | کلید سرویس ایمیل |
| `MAIL_FROM` | فرستندهٔ ایمیل‌ها |

توجه: احراز هویت با کد ۶ رقمی ایمیل پیاده‌سازی شده است؛ تا وقتی کلید سرویس ایمیل تنطیم نشود، کد در لاگ سرور قابل دیدن است (رایگان و بدون هزینه برای توسعه).

## ساختار صفحات

### فروشگاه

| مسیر | توضیح |
| --- | --- |
| `/` | صفحهٔ اول: اسلایدر، دسته‌بندی‌ها، محصولات جدید، پرفروش‌ها، تخفیف لحظه‌ای |
| `/category/$slug` | لیست محصولات با فیلتر قیمت/رنگ/سایز و مرتب‌سازی |
| `/product/$slug` | صفحهٔ محصول با گالری، تب‌ها، نقد و محصولات مرتبط |
| `/search`، `/offers` | جستجو و تخفیف‌ها |
| `/cart`، `/checkout`، `/order/$code` | سبد، تسویه، پیگیری سفارش و ارسال رسید |
| `/auth/*` | ورود، ثبت‌نام، تأیید ایمیل، بازیابی رمز |
| `/account/*` | پروفایل، سفارش‌ها، آدرس‌ها، علاقه‌مندی‌ها |
| `/blog`، `/blog/$slug` | مجله با سایدبار و دیدگاه‌های تو‌درتو |
| `/about`، `/contact`، `/stores`، `/faq` | صفحات اطلاعاتی |

### پنل مدیریت

| مسیر | توضیح |
| --- | --- |
| `/admin` | داشبورد: درآمد، تعداد سفارش، نمودار فروش روزانه، کارهای در انتطار |
| `/admin/products` | لیست محصولات با ویرایش سریع قیمت، موجودی، تخفیف ساده و زمان‌دار |
| `/admin/products/new` | فرم کامل افزودن محصول: تصاویر (آپلود)، ویژگی‌ها، دسته، سایز/رنگ |
| `/admin/categories` | دسته‌بندی درختی با نوع «پوشاک» (انتخاب سایز در سفارش) |
| `/admin/orders` | سفارش‌ها، تغییر وضعیت، بررسی رسید کارت‌به‌کارت |
| `/admin/coupons` | کدهای تخفیف درصدی/مبلغی |
| `/admin/posts` | مدیریت مقالات مجله + آپلود کاور |
| `/admin/comments` | تأیید/رد دیدگاه‌ها و نقدهای محصول |
| `/admin/customers` | مشتریان، پیام‌های تماس، خبرنامه |
| `/admin/settings` | شمارهٔ کارت، کرایهٔ ارسال، سقف ارسال رایگان، متن اعلان |

## روش پرداخت

درگاه بانکی متصل نیست. دو روش فعال است:

1. **کارت‌به‌کارت** — مشتری مبلغ را واریز و رسید را در صفحهٔ سفارش آپلود می‌کند؛ مدیر در `/admin/orders` تأیید می‌کند.
2. **پرداخت در محل** — سفارش مستقیم به وضعیت «در حال آماده‌سازی» می‌رود.
